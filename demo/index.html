read-write-xlsx

Read and write .xlsx files in the browser and Node.js, with zero dependencies.

GitHub npm

1 Read a file

Drop any .xlsx file from Excel, LibreOffice, Google Sheets and so on. It's parsed on this page with readXlsxSheets(). Nothing is uploaded.


      

      

    


    
    

      

        
2 Write a file

        
Pick an example and edit the code if you like, then run it. The file is built in the page, read back so you can check the result, and offered as a download you can open in Excel.

import { readXlsx, writeXlsx } from 'read-write-xlsx'

const rows  = await readXlsx(input.files[0])          // File, Blob, ArrayBuffer, Uint8Array
const bytes = await writeXlsx([['Hello', 'World']])   // → Uint8Array
